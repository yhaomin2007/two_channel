# UW–Madison ATH 2026 baseline

The original Ni–5Cr / Ni–20Cr data and baseline cases are already stored in the repository:
- `original_cases/Ni-5Cr.rar`
- `original_cases/Ni-20Cr.rar`
- `references/ATH_2026_two_channel_corrosion_model_in_MOSCATO(1).pdf`

These are existing original benchmark files; this release does not reinterpret or overwrite them.
The ATH report and its original plots are the authoritative provenance for this baseline.
Avoid confusing wt.% and at.% Cr, and distinguish independently measured grain sizes from model assumptions.
